### 设计基调

- 主色：蓝色渐变，例如 `#2563EB → #38BDF8`
- 背景：浅色，可用低饱和蓝灰渐变
- 卡片：半透明白色玻璃拟态（`rgba(255,255,255,0.6~0.75)` + `backdrop-filter: blur`）
- 圆角：较大圆角，约 `12px ~ 16px`
- 阴影：柔和阴影，避免厚重
- 字体：系统字体优先，中文友好
- 整体感觉：干净、现代、轻量、不花哨

## 2. 布局结构

你更喜欢哪种布局？

- **左侧边栏 + 主内容区**：适合环境/插件/内核导航，类似 VS Code / 邮箱客户端。
- **顶部导航 + 卡片式内容**：类似管理后台，更适合非技术用户。
- **仪表盘式首页**：一屏展示所有环境状态、插件状态、内核状态。
- **多标签页**：环境、插件市场、内核管理作为独立 Tab。
- **混合式**：首页仪表盘 + 左侧导航 + 详情页。

### 技术栈建议（推荐方案）

推荐使用 **Tauri 2 + React + TypeScript + Vite**，原因：

- 体积小、内存占用低，适合 Windows 10/11。
- 前端用标准 Web 技术，同一套代码可以同时发布为：
  - Windows 桌面应用（Tauri）
  - Web 管理页面（Vite + 浏览器访问）
- Rust 后端可以安全地调用 `dsh` CLI、管理进程、读写配置。
- 支持系统托盘、通知、快捷键、窗口控制等桌面能力。
- 玻璃拟态效果在 WebView2 / 浏览器中都能较好实现。

结构建议：

```text
apps/
├─ launcher/            # Tauri 桌面壳 + Rust 命令
└─ shell-web/           # React + TS + Vite 前端（桌面和 Web 共用）
```
