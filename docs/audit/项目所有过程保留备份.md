## 1. 项目一句话

**godsh** —— DeepSeek Harness（dsh）的图形化环境配置启动器（类比 Anaconda Navigator）：管理 Profile（环境）、插件市场/分配、内核、DSH 本体环境（base + 并列），可 Web 或 Tauri 桌面运行。

## 2. 技术栈与形态

| 层 | 技术 |
| --- | --- |
| 后端 | Node.js ≥20 · 纯 TS ESM · node:http · esbuild 单文件（server.mjs ~85KB） |
| 前端 | Vite 5 · React 18 · TS · 玻璃拟态 CSS（浅色 + 深色） |
| 桌面 | Tauri 2（Rust，`crate-type=["rlib"]`，GNU/MinGW 工具链）+ WebView2 |
| 安装 | 自定义 NSIS 安装器（exe 旁放 WebView2Loader.dll）+ 便携 ZIP |

## 5. 构建 / 运行 / 测试（复现方法）

```powershell
pnpm install                     # 装依赖
pnpm typecheck                   # 后端 + 前端 tsc
pnpm build:web                   # Web 前端
pnpm build:server                # 后端单文件
pnpm serve                       # Web 模式 http://127.0.0.1:4780
pnpm launcher <cmd>              # CLI（detect/profiles/start/dsh-envs/reset 等）
pwsh scripts/make-release.ps1 -Version x.y.z   # 桌面发布（tauri build 内嵌前端 + NSIS + ZIP + 校验和）
```

## 6. 关键决策与踩坑记录（重要）

1. **`dsh web` 是 `--profile web` 硬编码别名**，不接受 `--profile`；启动任意 Profile 用 `dsh --profile X --port P --no-open`。
2. **统一内核不能用 `--patch` 注入单行 web-app**（缺 webServer 服务启动失败）；正确做法是把 `@deepseek-ai/dsh-web-app` 并入 Profile 的 `dsh.profile.bundles`（bundle patch 加载完整 Web 表面），且**无需安装依赖**（从 dsh 安装目录解析）。
3. **Windows cmd shim**：`child.pid` 是 cmd.exe shim 的 pid；父进程退出后真实 dsh（node）被孤儿化但仍在监听 → 判活以**端口就绪**为准，停止时**按端口反查真实进程**（netstat）再 taskkill /T。
4. **BOM 陷阱**：Windows PowerShell `Set-Content -Encoding UTF8` 写 BOM，会导致 JSON.parse / serde_json 失败；所有写文件用 `[IO.File]::WriteAllText`（无 BOM）。
5. **pnpm.ps1 回显噪音**：pnpm 的 .ps1 包装把命令回显写到 stderr，`$ErrorActionPreference=Stop` 下会误判；用 `$LASTEXITCODE` 显式检查。
6. **GNU 工具链桌面构建**：路径不能含空格（同步到 `%USERPROFILE%\godsh` 构建）；cdylib 导出表溢出 → `crate-type=["rlib"]`；`tauri build` 才会内嵌前端（`cargo build` 会用 devUrl 5173 导致 404）。
7. **Windows 原生 DLL 文件锁（sharp/koffi）**：dsh 运行中 `npm install -g` 更新 dsh 会 EBUSY；Launcher 在安装/更新前拦截运行中环境。**本机曾因此损坏全局 dsh（包文件被删、shim 丢失）**，恢复方法：包文件完好时手动重建 npm 标准 shim（dsh.cmd / dsh.ps1 / dsh），或停止 harness 后重装。已实测 `dsh --version` 恢复 0.1.1-rc.1。
8. **版本号误读**："0.8rc" = 早先的 `0.1.0-rc.8`；当前安装 0.1.1-rc.1（检测与 package.json 一致），最新 0.1.1-rc.2。版本显示已改"完整版本号 + 来源标注"。
9. **重置副作用**：`all`/`dsh-all` 会真实删除 Profile 目录 / DSH_HOME——本机真实 profiles 曾因此被清空（现仅剩官方 web 模板），UI 已加强确认（dsh-all 需输入 DELETE）。
10. **本环境 pwsh 怪癖**：`Where-Object` 对 ConvertFrom-Json 对象的属性比较不可靠（返回空）；测试脚本统一用 `ForEach-Object` 投影 + `-contains` 规避。
