# godsh v0.3.7

godsh — DeepSeek Harness 图形化环境配置启动器（Anaconda Navigator 类比）。

## 下载

- godsh-0.3.7-x64-setup.exe — Windows 安装器
- godsh-0.3.7-x64.zip — 便携版（解压即用）

## v0.3.7 更新

- **单环境单端口互斥与旧端口彻底自清**：
  - 启动、重启或更改端口时，系统自动反查并彻底清理该 Profile 在本机的所有旧进程与残留端口，杜绝端口环境污染与多进程文件锁冲突。
  - 解决更新插件或重启后多端口同时可访问、界面加载版本不一致的根本问题。
- **系统设置新增「允许自定义多端口并发」开关**：
  - 默认关闭（严格单环境单端口互斥）。
  - 用户可在「设置」页自主开启“允许自定义多端口并发”，按需满足多端口并存场景。
- **环境页新增「🔄 重启」操作**：
  - 环境运行中支持一键优雅重启（平滑释放旧端口并重新拉起新实例）。
- **保留全部既有功能**：浏览器网址应用化（独立窗口不白屏）、发布年龄自愈、Junction 依赖修复、22 分类一键分配等。

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Windows 11 自带）
- 已安装 DeepSeek Harness（dsh CLI）与 Node.js ≥ 20
