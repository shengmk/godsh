# godsh v0.2.7

godsh — DeepSeek Harness 图形化环境配置启动器（Anaconda Navigator 类比）。

## 下载

- godsh-0.2.7-x64-setup.exe — Windows 安装器
- godsh-0.2.7-x64.zip — 便携版（解压即用）

## v0.2.7 更新

- **插件分配页每行「更新」**：单个插件一键更新（官方内核 bundle 自动维护提示）
- **每个环境「全部更新」**：一键更新该环境全部已安装插件
- **启动加载画面**：可爱风格的启动页（说明文字 + 进度加载框 + 动画），启动时并行检查更新 / 预热插件市场 / 优化加载
- **拖动转移**：跨环境拖动插件 = 剪切并复制（自动安装到目标环境）
- **市场已安装状态稳定**：不因其他操作闪变，卸载才移除

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Windows 11 自带）
- 已安装 DeepSeek Harness（dsh CLI）与 Node.js ≥ 20
