# godsh v0.5.1

godsh — DeepSeek Harness 图形化环境配置启动器（Anaconda Navigator 类比）。

## 下载

- godsh-0.5.1-x64-setup.exe — Windows 安装器
- godsh-0.5.1-x64.zip — 便携版（解压即用）

## v0.5.1 更新（仓库沙箱中枢、4 端网络隔离与动态安全端口专版）

### 📦 插件仓库沙箱中枢（Plugin Vault，就绪态插件管理池）
- **物理沙箱存储池**：彻底解耦用户自建临时 profiles 暂存方式，落盘于沙箱数据存储池；
- **一键导入本地插件**：支持本地插件源码文件夹 / .tgz 一键扫描导入，自动读取 package.json 元数据；
- **插件市场快捷暂存**：市场卡片新增「📦 暂存」按钮，随选随存；
- **瞬时部署与伴随依赖自愈**：分配页新增沙箱中枢抽屉，支持一键「⚡ 分发」到目标环境，并内置**伴随服务驱动自愈**（分发 `dsh-web-search-pro` 自动补全 `@anweat/dsh-browser`，杜绝驱动缺失闪退）；
- **差量版本自动比对**：支持一键检查沙箱插件版本更新。

### 🛡️ 4 端网络隔离与动态随机安全端口引擎（Dynamic Safe Port Allocator）
- **双重探活验证引擎**：新增 `packages/core/src/port-engine.ts`，结合 netstat 底层端口反查与 Node.js Socket 独占性监听测试；
- **动态随机协商**：在用户未自定义端口时，启动与重启环境自动在 `3200 ~ 3999` 区间内动态随机分配未占用安全端口，杜绝 3080/3081 端口碰撞导致的闪退；
- **4 端网络收敛**：启动参数严格绑定 `--host 127.0.0.1` 本地回环，杜绝内网未授权访问。

### ⚡ 核心缺陷彻底修复与控制台性能重构（方案 1 落地）
- **DSH 更新加速与防锁死**：自动注入 `npmmirror` 极速源、放行原生包编译脚本、提供 EPERM 占用诊断提示；
- **持久化任务日志卡片**：彻底修复任务日志框被 unmount 消失的 Bug，重构为支持“复制日志”与“清空日志”的持久卡片；
- **DSH 环境页面新增「🔄 刷新」按钮**：支持一键穿透清空探测缓存与版本缓存；
- **控制台页面秒开与微光骨架屏**：解耦并发数据加载，消除冒号与横线，体验丝滑流畅。

# godsh v0.4.1

godsh — DeepSeek Harness 图形化环境配置启动器（Anaconda Navigator 类比）。

## 下载

- godsh-0.4.1-x64-setup.exe — Windows 安装器
- godsh-0.4.1-x64.zip — 便携版（解压即用）

## v0.4.1 更新（Advanced 高级特性专版）

### 💾 页面常驻存储（KeepAlive，解决换页重载与状态丢失）
- **轻量 KeepAlive DOM 挂载容器**：
  - 访问过的页面常驻挂载于 DOM，切换导航时仅切换显隐，不卸载组件。
  - 彻底解决“换个页面就要重新加载”痛点：已拉取数据、滚动位置、多选勾选、搜索关键词、表单草稿等 100% 保持！
- **内存数据缓存层（Memory Cache Layer）**：
  - 市场数据、环境状态支持带 TTL 的内存缓存，换页瞬间直达零闪白。

### 📋 常驻全局任务中心（Task Center，解决更新面板消失）
- **右下角常驻悬浮任务微件**：
  - 显示当前正在后台运行的任务数量与脉冲指示器。
  - 单击展开全局任务抽屉，支持实时查看终端流式日志、进度条、成功/失败状态与历史记录。
- **任务永不丢失**：
  - 无论在哪个页面触发「环境插件全部更新」、「工作流运行」或「批量安装」，切到其它页面甚至跨页操作，任务继续在后台可靠推进并持续更新全局日志。
  - 任务完成后自动显示状态摘要并支持一键清空已完成记录。

### ⚡ Advanced 配置化工作流与批量规则（C1 / C3 / C4）
- **C1: 配置化多步工作流引擎（Workflows）**：
  - 内置「开发套件工作流 (Developer Suite)」、「AI 智能体对话流 (AI Agent Stack)」及「极简纯净流 (Minimal Clean)」。
  - 一键顺序自动化完成「创建环境 → 批量安装插件 → 写入配置补丁 → 注入分配关系」，全程实时输出至全局任务中心。
- **C3: 批量规则与环境克隆同步（Batch Rules & Clone）**：
  - 支持环境间 1:1 克隆：将源环境的全部 bundles 列表与插件分配规则一键批量同步并应用到目标环境。
- **C4: 一键环境包导出与导入（Profile Template Package Export / Import）**：
  - **导出环境包**：右键环境卡片选择「📤 导出环境包 (JSON)」，将该环境的 bundles、所有插件依赖（精准版本号）、cordis.patch.yml 完整层结构一键导出为独立单文件配置包。
  - **导入环境包**：工具栏点击「📥 导入环境包」，选择 JSON 文件一键还原新建环境并自动拉起依赖准备，轻松实现跨机器、跨设备完美复现！

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Windows 11 自带）
- 已安装 DeepSeek Harness（dsh CLI）与 Node.js ≥ 20
