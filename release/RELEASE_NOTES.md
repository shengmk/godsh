## 🌟 v0.6.1 进阶升级：双模主题落地、动态呼吸极光与体验打磨

基于 **UI-UX-Pro-Max 智能设计库** 规范，godsh v0.6.1 全面解决了任务中心白框缺陷、深色过黑死板问题，完整落地了 Clean Frosted Light 浅色主题架构，并深度解密了插件沙箱的版本判定逻辑。

### 🎨 1. UI-UX-Pro-Max 浅色主题 (Clean Frosted Light) 完整落地
- **全站 CSS 设计令牌重构**：完整声明 `[data-theme='light']` 体系，采用柔和石板白底板（`#f8fafc`）与纯白毛玻璃卡片（`rgba(255,255,255,0.85)`）；
- **极客终端防眩光保护 (Dev Terminal Contrast Guard)**：在浅色模式下，代码控制台、审计日志与系统终端保持专业黑底高对比度（`#0f172a`），既护眼又确保代码荧光高亮识别；
- **顶栏即时昼夜模式切换**：在顶栏右侧新增极简 `Sun` / `Moon` 矢量按钮，支持一键平滑切换。

### ✨ 2. 深色主题电影级质感升华与动态呼吸极光
- **Cosmic Slate 深空灰阶底座**：彻底告别 OLED 极纯黑（`#020203`）带来的死寂感，底座提升至 `#0b0d14` 与 `#121520`；
- **24s 动态浮动极光**：引入 `@keyframes aurora-float` 硬件加速流体呼吸漂移动效，天顶电光靛蓝（`0.22`）、腹底极光紫（`0.16`）与深海翡翠（`0.10`）三光源交融；
- **24px 精密发丝点阵网格**：叠加极客点阵图层，赋予系统通透的立体纵深与生命力。

### 🛡️ 3. 页面外黑框消解与窗口沉浸
- **视口边距无缝融合**：通过满铺环境光消除了主视口外围 padding 与纯黑卡片形成的“黑边框包裹”假象；
- **Tauri 窗口沉浸**：在 `tauri.conf.json` 中注入 `"theme": "Dark"` 保证视窗初始化底衬色彩统一。

### 🔧 4. 系统任务中心「两个白框」彻底根除
- **胶囊分段选择器重写**：补齐 `.tab-pill-group` 与 `.pill-btn` 样式声明，消灭 WebView2 原生灰白立体按钮，支持深浅双模平滑适配。

### 📦 5. 插件沙箱版本判定机制深度解密与透明化
- **沙箱说明交互**：顶部工具栏新增专属「更新机制说明」弹窗，直观告知用户为什么沙箱采用智能差量升级策略（`hasUpdate: true`）、本地收割资产保护（`source: 'local'`）及私有包 404/超时保护策略。
