# godsh v0.4.0

godsh — DeepSeek Harness 图形化环境配置启动器（Anaconda Navigator 类比）。

## 下载

- godsh-0.4.0-x64-setup.exe — Windows 安装器
- godsh-0.4.0-x64.zip — 便携版（解压即用）

## v0.4.0 更新（大版本：性能 + 界面 + 稳定性）

### ⚡ 性能大幅提升
- **HTTP 全链路 gzip 压缩**：市场数据 1925KB → 550KB（-71%），静态资源与所有 JSON 响应自动压缩
- **静态资源内存缓存 + 强缓存头**：dist 文件常驻内存，带 hash 资源一年强缓存，页面加载提速数倍
- **市场搜索/排序/分类全本地化**：一次加载市场数据，搜索、热门/最新排序、分类筛选全部前端内存完成，零网络请求、零等待
- **分配页轻量刷新**：操作后只重拉分配与可分配清单（4 请求 → 2 请求），交互更流畅

### 🎨 界面全面重设计（庄重专业）
- 视觉语言从「活泼玻璃拟态」升级为「清晰庄重」：深靛蓝主色、中性灰背景、实白卡片、细边框、克制圆角
- 清理装饰性 emoji（💡📂⚡🖧🌀⚠️），保留功能性操作图标
- 导航激活态改为左侧指示条，启动画面简洁化，动效克制
- 深色主题同步优化

### 🧩 插件管理体验
- 市场页新增**分类筛选**（22 类 + 数量），与搜索/排序协同
- 批量安装失败项支持**单条重试**
- 已安装状态改为后端权威刷新（消除残留显示）

### 🐛 稳定性修复
- 官方内核 bundle 保护补全（dsh-headless 纳入，与后端一致）
- 修复市场已安装状态竞态残留

### 延续既有能力
单环境单端口互斥、DSH Desktop/浏览器应用化打开、发布年龄自愈、Junction 依赖修复、按分类自动分配、自定义端口、悬停简介、可视化进度

## 环境要求

- Windows 10 / 11（需 WebView2 运行时，Windows 11 自带）
- 已安装 DeepSeek Harness（dsh CLI）与 Node.js ≥ 20
